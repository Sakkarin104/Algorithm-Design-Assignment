# ข้อ 2 การตรวจสอบ Palindrome

### 1. คำอธิบายแนวคิดของอัลกอริทึมแต่ละวิธี
* **Algorithm 1 (Reverse and Compare):** ทำการสร้างสตริงใหม่ที่เรียงลำดับตัวอักษรย้อนกลับจากสตริงต้นฉบับ จากนั้นนำสตริงทั้งสองมาเปรียบเทียบกัน หากเหมือนกันทุกประการแสดงว่าเป็น Palindrome
* **Algorithm 2 (Recursive Two-Pointer):** ใช้ตัวชี้ (Pointer) สองตัว คือ `left` ชี้ที่ตัวอักษรแรกสุด และ `right` ชี้ที่ตัวอักษรสุดท้ายสุด นำมาเปรียบเทียบกัน หากตรงกันให้ขยับตัวชี้เข้าหากันแล้วเรียกซ้ำเพื่อตรวจสอบคู่ถัดไปจนกว่าตัวชี้จะชนกันตรงกลาง
  * **Base Case (กรณีฐาน):** 
    1. `if (left >= right)`: เมื่อตัวชี้วิ่งมาชนกันหรือไขว้กันตรงกลาง แสดงว่าตรวจสอบครบทุกคู่แล้วและตรงกันทั้งหมด เมธอดจะคืนค่า `true`
    2. `if (s.charAt(left) != s.charAt(right))`: ตรวจพบว่าตัวอักษรคู่ปัจจุบันไม่ตรงกัน จะคืนค่า `false` และหยุดการทำงานทันที
  * **Recursive Case (กรณีเวียนเกิด):** `return isPalindromeRecursive(s, left + 1, right - 1);` หากตัวอักษรคู่ปัจจุบันตรงกัน จะเรียกตัวเองซ้ำโดยขยับตัวชี้ `left` ไปขวา 1 ตำแหน่ง และ `right` ไปซ้าย 1 ตำแหน่ง

*(หมายเหตุ: ทั้ง 2 อัลกอริทึมมีการทำความสะอาดข้อมูล (Pre-processing) ก่อนเริ่มตรวจสอบ โดยแปลงเป็นตัวพิมพ์เล็กทั้งหมด ตัดช่องว่าง และเครื่องหมายวรรคตอนทิ้ง เพื่อให้สอดคล้องกับเงื่อนไขเพิ่มเติมของโจทย์)*

### 2. Pseudocode หรือผังขั้นตอนการทำงาน
**Algorithm 1: Reverse and Compare**
```text
FUNCTION isPalindromeByReverse(s)
    cleaned_s = REMOVE NON-ALPHANUMERIC AND CONVERT TO LOWERCASE(s)
    reversed_s = REVERSE(cleaned_s)
    IF cleaned_s == reversed_s THEN
        RETURN true
    ELSE
        RETURN false
    END IF
END FUNCTION
```

**Algorithm 2: Recursive Two-Pointer**
```text
FUNCTION isPalindromeRecursive(s, left, right)
    IF left >= right THEN
        RETURN true
    END IF
    
    IF s[left] != s[right] THEN
        RETURN false
    END IF
    
    RETURN isPalindromeRecursive(s, left + 1, right - 1)
END FUNCTION
```

### 5. การวิเคราะห์ Time Complexity
* **Algorithm 1 (Reverse and Compare):** 
  * **Best-case และ Worst-case:** $\mathcal{O}(n)$ เสมอ เนื่องจากไม่ว่าสตริงจะเป็น Palindrome หรือไม่ (เช่น กรณีที่ตัวอักษรคู่แรกไม่ตรงกัน) โปรแกรมก็ยังต้องทำงานเต็มรูปแบบเพื่อสร้างสตริงกลับด้านทั้งชุดขึ้นมาใหม่ก่อนเสมอ
* **Algorithm 2 (Recursive Two-Pointer):**
  * **Best-case Time Complexity:** $\mathcal{O}(1)$ เกิดขึ้นในกรณีที่ตัวอักษรคู่แรกไม่ตรงกัน โปรแกรมจะหยุดทำงานและคืนค่า `false` ได้ทันทีตั้งแต่รอบแรก
  * **Worst-case Time Complexity:** $\mathcal{O}(n)$ เกิดขึ้นในกรณีที่สตริงเป็น Palindrome ซึ่งโปรแกรมจะต้องเปรียบเทียบและเรียกซ้ำลึกเข้าไปจนถึงกึ่งกลางของสตริง (ทำงาน $rac{n}{2}$ รอบ)

### 6. การวิเคราะห์ Space Complexity
* **Algorithm 1:** $\mathcal{O}(n)$ เนื่องจากต้องใช้พื้นที่ในหน่วยความจำเพื่อสร้าง Object ของสตริงตัวใหม่ที่เรียงย้อนกลับ
* **Algorithm 2:** $\mathcal{O}(n)$ เนื่องจากใช้พื้นที่ใน Call Stack ซ้อนกันตามความลึกของการเรียกซ้ำ (สูงสุด $rac{n}{2}$ ชั้น)

### 7. การเปรียบเทียบข้อดีและข้อจำกัดของแต่ละอัลกอริทึม
* **Algorithm 1:** 
  * **ข้อดี:** เขียนง่ายและตรงไปตรงมา
  * **ข้อจำกัด:** ไม่มีความสามารถในการหยุดทำงานก่อนครบทุกตัวอักษร (Early Exit) ทำให้สิ้นเปลืองเวลาประมวลผลและหน่วยความจำในการจำลองสตริงใหม่ทั้งชุดเสมอ
* **Algorithm 2:** 
  * **ข้อดี:** มีความสามารถในการหยุดทำงานก่อน (Early Exit) อย่างสมบูรณ์ หากพบตัวอักษรคู่ใดไม่ตรงกันก็ตัดจบได้ทันที ช่วยลดภาระการประมวลผลได้มาก
  * **ข้อจำกัด:** หากนำไปใช้ตรวจสอบข้อความที่มีความยาวมหาศาลมากๆ อาจกินพื้นที่ Call Stack จนเกิดข้อผิดพลาดได้

### 8. สรุปว่าอัลกอริทึมใดเหมาะสมกว่าภายใต้เงื่อนไขใด
**Algorithm 2 (Recursive Two-Pointer) มีความเหมาะสมมากกว่า** เนื่องจากมีประสิทธิภาพโดยรวมสูงกว่า การมีคุณสมบัติ Early Exit ทำให้เมื่อเจอข้อมูลที่ไม่ใช่ Palindrome โปรแกรมจะตัดจบได้อย่างรวดเร็ว ในขณะที่วิธี Reverse จะบังคับกินทรัพยากรเต็มจำนวนในทุกกรณีโดยไม่จำเป็น
