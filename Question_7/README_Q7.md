# งานทดลองเปรียบเทียบประสิทธิภาพ (Performance Experiment)

### 1. ตารางผลการทดลอง
การทดลองวัดเวลาการทำงานจริง (หน่วย: นาโนวินาที - Nanoseconds) จากการทดสอบขนาดละ 5 ครั้งแล้วหาค่าเฉลี่ย ตามโจทย์การทดลองเปรียบเทียบประสิทธิภาพของแบบฝึกหัด

| ขนาดข้อมูล n | Alg 1 (Brute Force) | Alg 2 (Rec Two-Pointer) | Alg 3 (Binary Search) |
| :--- | :--- | :--- | :--- |
| **100** | 41,320 ns | 4,300 ns | 14,600 ns |
| **1,000** | 538,280 ns | 8,460 ns | 202,560 ns |
| **10,000** | 7,281,420 ns | 28,180 ns | 240,500 ns |
| **100,000** | > 10,000,000,000 ns | FAILED (StackOverflow) | 2,517,480 ns |

---

### 2. ตอบคำถามท้ายการทดลอง

**1. ผลการทดลองสอดคล้องกับ Big-O ที่วิเคราะห์ไว้หรือไม่**
* สอดคล้องอย่างยิ่ง Brute Force มี Time Complexity เป็น O(n^2) ทำให้เวลาการทำงานเพิ่มขึ้นแบบก้าวกระโดดเมื่อขนาดข้อมูลใหญ่ขึ้น ในขณะที่ Binary Search (O(n log n)) และ Recursive Two-Pointer (O(n)) ใช้เวลาเพิ่มขึ้นในอัตราที่ช้ากว่ามาก

**2. อัลกอริทึมใดเร็วที่สุดเมื่อข้อมูลมีขนาดเล็ก**
* Recursive Two-Pointer ทำงานได้เร็วที่สุดเมื่อข้อมูลมีขนาดเล็ก (เช่น n = 100) เนื่องจากไม่มี Overhead จากการทำงานของลูปซ้อนหรือขั้นตอนการคำนวณที่ซับซ้อน

**3. อัลกอริทึมใดเหมาะสมที่สุดเมื่อข้อมูลมีขนาดใหญ่**
* Binary Search หรือ Two-Pointer แบบวนลูปมีความเหมาะสมที่สุดเมื่อข้อมูลมีขนาดใหญ่ (เช่น n = 100,000) เพราะให้ความเร็วสูงและไม่เกิดปัญหาหน่วยความจำ Stack เต็ม

**4. Recursive Algorithm มีข้อจำกัดด้านหน่วยความจำอย่างไร**
* การเรียกฟังก์ชันแบบเวียนเกิดต้องใช้พื้นที่ใน Call Stack เก็บสถานะ เมื่อข้อมูลมีขนาดใหญ่มาก (เช่น n = 100,000) การเรียกซ้อนกันจะลึกเกินขีดจำกัด ส่งผลให้เกิดข้อผิดพลาด StackOverflowError และโปรแกรมหยุดทำงาน

**5. เหตุใดอัลกอริทึมที่มี Big-O เท่ากันจึงอาจใช้เวลาจริงแตกต่างกัน**
* Big-O เป็นตัววัดอัตราการเติบโตเชิงทฤษฎี แต่เวลาจริงอาจต่างกันได้จากค่าคงที่แฝง (Hidden Constants) เช่น การเข้าถึงหน่วยความจำ การจัดการโครงสร้างข้อมูล หรือกระบวนการเบื้องหลังของระบบปฏิบัติการ

**6. การวัดเวลาเพียงครั้งเดียวเพียงพอหรือไม่ เพราะเหตุใด**
* ไม่เพียงพอ เพราะการประมวลผลของคอมพิวเตอร์ในแต่ละครั้งอาจถูกรบกวนจากกระบวนการเบื้องหลัง ทำให้เกิดค่าความคลาดเคลื่อน การทดลองซ้ำหลายครั้ง (เช่น 5 ครั้ง) แล้วหาค่าเฉลี่ยจึงจะได้ผลลัพธ์ที่แม่นยำและน่าเชื่อถือกว่า
